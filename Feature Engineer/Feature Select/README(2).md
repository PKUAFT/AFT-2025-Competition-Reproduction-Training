# 特征重要性（Feature Importance）

本模块以 Optiver 收盘价预测任务为背景，研究如何衡量拍卖行情及衍生因子对模型预测的贡献。通过比较树模型内置指标、模型解释方法和验证集置换实验，分析不同重要性指标的适用场景、排名一致性，以及噪声和多重共线性带来的影响。

## 1. 特征重要性评估方法

| 方法 | 基本原理 | 特点与局限 |
| --- | --- | --- |
| Gain | 衡量特征参与树节点分裂时带来的损失下降 | 直接反映模型训练贡献，但受树结构和相关特征影响 |
| Split | 统计特征被用于节点分裂的次数 | 计算简单，但分裂频繁不代表预测贡献大 |
| Cover | 衡量特征分裂所覆盖的样本权重（XGBoost 中通常基于 Hessian） | 反映影响范围，不直接代表预测效果 |
| SHAP | 将单个样本的模型预测分解为各特征的贡献，以平均绝对 SHAP 值衡量全局重要性 | 可解释贡献大小及方向，但计算成本较高，归因受特征依赖关系影响 |
| Mutual Information | 衡量特征与目标变量之间的统计依赖程度 | 可识别非线性关系，但不直接衡量特征在组合模型中的增量贡献 |
| Permutation Importance | 打乱验证集中的某个特征，观察模型预测误差的变化 | 直接衡量已训练模型对该特征的依赖，但相关特征可能相互替代 |

## 2. 置换重要性与多重共线性

置换实验采用时序交叉验证，在每个训练折拟合模型，再对验证折进行特征置换。以 MAE 为例，重要性可表示为：

$$I_j = MAE_{permuted,j} - MAE_{baseline}$$

数值越大，表示打乱该特征后预测误差增加越多。负值则表示该次置换后误差反而下降，不宜直接视为稳定的负贡献。

针对金融因子普遍存在的相关性问题，Notebook 对比三种实验：

- **普通置换**：逐个打乱特征，作为基准。
- **相关性裁剪后置换**：对相关系数超过 0.9 的特征对删除其中一个，再评估剩余特征的重要性。
- **分组置换**：联合打乱一组相关特征，衡量该组信息对模型预测的整体贡献。

当多个因子携带相似信息时，单独打乱其中一个因子可能不会明显降低模型表现，导致其重要性被低估。分组置换有助于识别这类共同贡献。此外，实验通过引入随机噪声和共线性特征，观察重要性排序是否发生变化。

## 3. 多方法对比与结果解读

对不同重要性指标进行排序，比较 Top-K 特征重合度、排名相关性和高排名特征之间的相关性。Gain、SHAP 与置换重要性分别侧重训练过程、预测归因和验证集预测贡献，排名存在差异是正常现象。多种方法共同识别的高重要性特征值得进一步验证，但重要性高并不等于具有稳定的样本外预测能力，也不代表因果关系。
